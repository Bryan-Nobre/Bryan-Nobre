## 👨‍💻 Sobre Mim

Sou **Técnico em Desenvolvimento de Sistemas**, com interesse em tecnologia e desenvolvimento Full Stack. Gosto de transformar ideias em aplicações funcionais, buscando unir uma boa estrutura de código a interfaces intuitivas e eficientes.

- 💻 Atualmente focado no desenvolvimento de aplicações web e sistemas completos.
- 🚀 Tenho trabalhado na construção de plataformas SaaS, sistemas de gestão e integrações com bancos de dados.
- 📚 Sempre buscando aprimorar meus conhecimentos, explorar novas tecnologias e aplicar boas práticas de desenvolvimento.
- 🎯 Meu objetivo é construir soluções úteis, bem estruturadas e preparadas para necessidades reais.
